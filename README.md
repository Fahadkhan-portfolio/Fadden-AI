# 🤖 FaddenAI — Modern AI Chat Assistant

A clean, responsive AI chat platform integrated with OpenRouter models, powered by secure Vercel Serverless backend architecture.

![Deployment](https://img.shields.io/badge/Vercel-Live-brightgreen?style=for-the-badge&logo=vercel)
![Architecture](https://img.shields.io/badge/Backend-Serverless%20API-black?style=for-the-badge&logo=vercel)

---

## 🔥 Key Features
- **Secure Backend Routing:** API keys are protected on the server side via Vercel Serverless functions (`/api/chat.js`).
- **Dynamic AI Models:** Seamlessly routes prompts through OpenRouter endpoint models.
- **Modern Interface:** Includes Theme Toggle (Dark/Light), auto-resizing input, and quick-prompt suggestions.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Modern CSS, Vanilla JS
- **Backend:** Node.js / Vercel Serverless Functions
- **API:** OpenRouter AI API
